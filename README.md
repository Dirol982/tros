# tros-kpp.by — редизайн

Новый сайт ЧПУП «ТехноЛекарь» (ремонт тросов КПП и кулис, Минск). Статический HTML без CMS и PHP.

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная |
| `remont-trosov.html` | Ремонт тросов (бывшая «Неисправности тросов») |
| `remont-kulis.html` | Ремонт кулис (бывшая «Неисправности кулис») |
| `izgotovlenie-trosov.html` | Изготовление тросов по размерам (новая) |
| `diagnostika.html` | Диагностика своими руками |
| `po-belarusi.html` | Ремонт по Беларуси (новая) |
| `kontakty.html` | Контакты |
| `izmeneniya.html` | Отчёт для клиента: что изменилось (noindex) |

## Сборка

Страницы генерируются из `tools/`, общие шапка, подвал и SEO-разметка лежат в `tools/layout.py`.

```bash
python3 tools/build.py
```

Скрипт пересобирает все `.html`, `sitemap.xml` и `robots.txt`. Правьте тексты в `tools/pages_*.py`, а не в готовых HTML.

## Перед запуском

- Подключить обработчик формы: сейчас `assets/app.js` только показывает сообщение.
- Добавить 301-редиректы из `deploy/nginx-redirects.conf`.
- Вернуть счётчик Яндекс Метрики (id 38205405 со старого сайта) и настроить цели.
- Добавить цены, свои фото и отзывы (список в `izmeneniya.html`, раздел «Нужно от вас»).
